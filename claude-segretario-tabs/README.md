# segretario-tabs

"Where was I?" for people who follow many Claude chats at once. Above the prompt, one tab for each of your most
recent chats (claude.ai and Claude Code) and projects, read from your Segretario (the shared memory every chat
reports to). Six tabs, an arrow for four more, and a History list of everything, newest first. A dot marks what is
waiting for you. Tap a tab to see the last thing done, the next step, what Claude is asking you, and a link that
opens the chat.

It needs the Segretario connector in the session (tools `chat_recenti` and `chat_aperte`). It only sends the
Segretario the titles, links and last activity of your Claude Code chats, never their content.
